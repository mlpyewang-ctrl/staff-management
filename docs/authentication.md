# 认证与密码管理说明

## 登录方式

系统使用基于用户名/密码的凭证认证（NextAuth CredentialsProvider），密码通过 bcryptjs 加密存储。

## 默认密码规则

- 通过管理后台 **人员岗位 → 新建账号** 创建的账号，系统会分配默认初始密码。
- 通过脚本批量导入的员工账号，默认密码为 `123456`。
- **创建/导入后请尽快在个人页面修改密码。**

## 密码修改

所有登录用户均可在 **个人信息** 页面的 **修改密码** 区域自助修改密码：

1. 进入侧边栏「个人信息」页面
2. 滚动到页面底部的「修改密码」卡片
3. 输入当前密码、新密码并确认
4. 点击「修改密码」提交

> 注意：修改密码时需要验证当前密码，新密码至少需要 6 个字符。

## 忘记密码

普通用户忘记密码时，请联系系统管理员在数据库层面重置密码。管理员可使用 Prisma Studio 或脚本直接更新对应用户的 `password` 字段（需使用 bcrypt 哈希）。

## 初始管理员

系统首次启动时，若数据库中不存在 ADMIN 角色用户，`prisma/seed.ts` 或 `createInitialAdmin()` 会自动创建一个初始管理员账号。

具体用户名和密码请参考部署时的环境配置或 seed 脚本输出，**不建议在生产环境使用默认密码**。
